# 서울대 수강검색 관련도 정렬

`sugang.snu.ac.kr`의 강좌검색 결과 페이지를 개선하는 Manifest V3 Chrome 확장프로그램입니다.

검색 후 사이트의 `엑셀저장`과 같은 서버 엔드포인트에서 전체 결과를 한 번 받아 다음과 같이 처리합니다.

- 교과목명과 부제명을 기준으로 관련도순 정렬
- Excel 전체 결과 기준 10개씩 페이지 표시
- 페이지 번호 클릭 시 서버 재조회 없이 즉시 전환
- 사이트의 결과 카드와 유사한 UI 유지
- 기존 로그인, 관심강좌, 장바구니, 수강신청, 일반 Excel 저장 코드는 변경하지 않음

## 설치

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 `snu-sugang-relevance-sorter` 폴더를 선택합니다.
5. 이미 열려 있던 수강신청 페이지가 있다면 새로고침합니다.

별도 빌드는 필요하지 않습니다. `vendor/xlsx.full.min.js`도 폴더에 포함되어 있습니다.

## 동작상 제약

- 확장프로그램은 사이트가 제공하는 Excel 저장 응답에 의존합니다. 사이트가 다음 학기 Excel 저장을 막거나, 점검·부하시간에 Excel 응답을 제한하면 관련도 정렬도 적용할 수 없습니다. 이 경우 원래 서버 결과를 다시 표시하고 오류 안내를 냅니다.
- 검색 결과가 수천 건이면 Excel 다운로드와 BIFF8 파싱 때문에 네트워크/PC 상태에 따라 잠시 기다릴 수 있습니다.
- 사이트 DOM, 폼 필드명, Excel 열 순서 또는 Excel 엔드포인트가 바뀌면 업데이트가 필요할 수 있습니다.
- 검색어가 없는 상세 조건 검색은 관련도 점수가 모두 같으므로 Excel 원래 순서를 유지합니다.
- 수강신청은 학교 정책과 서버 검증을 그대로 사용합니다. 이 확장프로그램은 자동 신청이나 보안문자 우회를 하지 않습니다.
